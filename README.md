# AI State Space Visualizers

Interactive HTML visualizers for small AI state-space search examples.

Open `index.html` to switch between:

- `4_queen_visual_logic.html`, with the original 4 Queen board design and logic walkthrough
- `hanoi_visualizer.html`, with the original Tower of Hanoi design and move debugger

`ai_state_space_visualizers.html` uses the same switcher as `index.html` for compatibility with the old filename.
