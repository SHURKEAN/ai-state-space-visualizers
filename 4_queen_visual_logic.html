                3. actions: finding possible moves
                

                    
actions loops through every square. If the square is 0, it creates an action for that position.

                    
def actions(self, state):
    acts = []
    for i in range(4):
        for j in range(4):
            if state[i][j] == 0:
                acts.append("o {} {}".format(i + 1, j + 1))
    return acts

                    
The code uses i + 1 and j + 1 because humans count rows and columns as 1, 2, 3, 4, but Python counts indexes as 0, 1, 2, 3.

                    
On an empty board there are 16 possible actions because 4 * 4 = 16.

                

            


            

                4. result: placing a queen and marking attacks
                

                    
result takes a state and an action, then returns the new board after that action.

                    
i, j = int(action.split(' ')[1]) - 1, int(action.split(' ')[2]) - 1

                    
This reads an action like "o 4 4". It converts it to Python indexes, so row 4, column 4 becomes i = 3, j = 3.

                    
new_state = convert_state_to_list(state)

                    
The board starts as tuples, but tuples cannot be changed. So the code converts the board to lists before editing it.

                    
if l == i and k == j:
    new_state[l][k] = 1
elif (l == i or k == j or abs(i - l) == abs(j - k)):
    new_state[l][k] = 2

                    
The first condition places the queen. The second condition marks attacked squares: same row, same column, or same diagonal.

                

            


            

                5. The diagonal formula
                

                    
This is the diagonal check:

                    
abs(i - l) == abs(j - k)

                    
Two squares are on the same diagonal when the row distance and column distance are equal.

                    
Example: queen at row 4, column 4. The square row 2, column 2 is diagonal because the row difference is 2 and the column difference is also 2.

                    
abs(3 - 1) == abs(3 - 1)
2 == 2

                

            


            

                6. goal_test: checking if the board is solved
                

                    
goal_test checks whether every row has at least one queen.

                    
def goal_test(self, state):
    bool_state = convert_state_to_list(state)

    for i in range(4):
        for j in range(4):
            bool_state[i][j] = state[i][j] == 1

    return all([any(bool_state[i]) for i in range(4)])

                    
state[i][j] == 1 becomes True if there is a queen and False if there is not.

                    
any(bool_state[i]) means “does this row contain at least one queen?”

                    
all(...) means “do all four rows contain a queen?”
